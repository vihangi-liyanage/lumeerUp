## Overview

LUMEERUP is a full-stack AI-powered career guidance platform that helps students, graduates, and career changers discover suitable career paths based on their skills, interests, educational background, and resume. The platform uses AI to provide personalized career recommendations, identify skill gaps, and suggest learning roadmaps.

## Features

* User registration and authentication
* User profile management
* Skills and interest assessments
* Resume upload and analysis
* AI-powered career recommendations
* Skill gap analysis
* Personalized learning roadmaps
* Progress tracking dashboard
* Responsive user interface

## Installation

1. Clone the repository

```bash
git clone <repository-url>
```

2. Install dependencies

```bash
npm install
```

3. Configure environment variables

Create a `.env` file and add the required configuration.

4. Start the development server

```bash
npm run dev
```
